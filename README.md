# 🕯️ Ofrenda de Código (Altar of the Departed Repositories)

> *"In the spirit of Día de los Muertos, open-source software never truly dies as long as its lessons and memory are kept alive on the altar."*

Built for **Hacktoberfest 2026: Week 4 — Ghost in the Machine (Halloween & Día de los Muertos)**.

---

## 🌟 What is Ofrenda de Código?

Every year, thousands of open-source projects reach the end of their lifecycle: maintainers burn out, frameworks shift, and once-essential libraries are archived into silent GitHub graveyards. Pioneer libraries like `request`, `moment.js`, `urllib2`, `bower`, and `coffeescript` carried the weight of the early web on their shoulders, yet their deprecation notices often read like quiet farewells.

**Ofrenda de Código** is an interactive, open-source AI-powered sanctuary where developers can honor, commune with, and resurrect deprecated open-source software:

1. **🏵️ The Marigold Altar (*Ofrenda*):** An atmospheric memorial featuring glowing candlelight, marigold petals (*cempasúchil*), peak weekly download metrics, and a poetic epitaph celebrating each library's service to the open-source community.
2. **👻 Séance Terminal (Ghost in the Shell):** Powered by Google's open-weight **Gemma 2**, developers can commune directly with the digital spirit of any departed repository—experiencing nostalgic conversations steeped in the technical idioms, constraints, and culture of its era (e.g. 2011 callback hell, ES5 polyfills, Python 2 vs 3 transitions).
3. **✨ The Resurrection Chamber (Code Transmutation):** Demonstrates how the soul of legacy code is reincarnated into modern 2026 idioms (async/await, strict TypeScript, native `fetch`, immutable date APIs, and modern Python 3.12).
4. **🎙️ Spoken Memorial Eulogy:** Solemn spoken eulogies narrated with **ElevenLabs**, giving voice to the code that once held the internet together.
5. **🕯️ Devotee Offerings:** Visitors can light virtual candles, place marigolds, or leave late-night coffees and farewell notes on the communal ofrenda wall.
6. **🔮 Summon Any Repository:** Enter any GitHub repository URL (e.g., `facebook/flux`, `angular/angular.js`, or personal archived projects) to generate a personalized altar and commune with its spirit.

## 🧠 Why Open Innovation Matters

The Week 4 Hacktoberfest challenge specifically asks: *Tell us why open innovation matters for what you built.*

1. **Sovereignty over the Grave:** Proprietary closed-source software dies behind corporate NDAs and disappears into non-existence when a startup goes bankrupt. Open source preserves its entire lineage—every commit, message, and bug—publicly.
2. **Offline Digital Preservation:** Powered by open weights (**Google Gemma 2**), *Ofrenda de Código* does not depend on a commercial AI subscription or external cloud API that may itself be deprecated tomorrow. It can run on an air-gapped machine 20 years from now.
3. **No Closed-Garden Censorship:** Open-weight models allow authentic historical simulation without sanitized corporate refusal to discuss software deprecation, legacy bugs, or ecosystem conflicts.

## 🚀 Quickstart & Local Installation

### Prerequisites
- Node.js v18+ (tested on Node.js v24)
- (Optional) [Ollama](https://ollama.com) running `gemma2:9b` or `gemma:2b` locally for 100% offline open-weight inference.

### 1. Clone & Install
\`\`\`bash
git clone https://github.com/your-username/ofrenda-de-codigo.git
cd ofrenda-de-codigo
npm install
\`\`\`

### 2. Configure Environment (Optional)
Copy `.env.example` to `.env`:
\`\`\`bash
cp .env.example .env
\`\`\`
*Note: If no API keys are provided, the application runs in sovereign offline mode with full built-in neural emulation, so you can test all features immediately!*

### 3. Run Development Servers
\`\`\`bash
npm run dev:all
\`\`\`
- Frontend Altar: `http://localhost:3000`
- Backend API: `http://localhost:3001`
